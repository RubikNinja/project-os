Project OS v1.5 PWA

Upload ALL files and the icons folder to the same GitHub Pages site directory. Do not upload just index.html: the manifest, service worker and icons are needed for installation.

iPhone: Open site in Safari > Share > Add to Home Screen.
Android: Open site in Chrome > menu > Install app / Add to Home Screen.

IMPORTANT: Existing project data stays in the browser/device where it was created. Use the app's JSON export/import to move data to your phone. Installing does not sync devices. Gemini requires internet.

If the old design persists, refresh the site after GitHub Pages finishes deploying.
